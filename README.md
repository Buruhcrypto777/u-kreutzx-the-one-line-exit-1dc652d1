Entry for the make.fun bounty [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

A pure-stdlib Python program (`main.py`) writes one line of a resignation letter to `/output/entry.txt`:

> I am resigning, effective immediately: I have just realized I cannot swim.

74 characters. The surprise is the job's core requirement inverted, with the punch landing on the very last word — the specific voice is instantly recognizable (a lifeguard), and it reads exactly like a letter a person could actually send. The program runs offline and produces byte-identical output on every run.
